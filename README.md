## 📖 Overview

This repository serves as a practical showcase and learning resource for numerical computing and data analysis using Python, with a strong emphasis on the NumPy library. It contains various Jupyter notebooks and a Python script that delve into core NumPy functionalities, data manipulation techniques, exploratory data analysis, and an introductory machine learning project using the Iris dataset. It's ideal for anyone looking to understand or refresh their knowledge of fundamental data science operations.

## ✨ Features

-   🎯 **NumPy Fundamentals**: Explore array creation, manipulation, indexing, slicing, and broadcasting techniques.
-   ➕ **Mathematical & Statistical Operations**: Perform a wide range of mathematical functions, aggregations, and statistical computations on numerical data.
-   🌱 **Data Preprocessing & Analysis**: Practice loading, cleaning, and transforming data, demonstrated particularly in the Iris dataset project.
-   🌿 **Introductory Machine Learning**: Implement basic classification concepts using the well-known Iris dataset.
-   📈 **Exploratory Data Analysis (EDA)**: Conduct preliminary data investigations to discover patterns and insights, potentially involving data visualization (libraries like Matplotlib/Seaborn are commonly used in such projects).
-   🎨 **Enhanced Console Output**: Experiment with the `rich` library for improved terminal formatting and display in development environments.

## 🚀 Quick Start

To run the notebooks and scripts in this repository, you'll need Python and Jupyter Notebook installed.

### Prerequisites

-   **Python 3.x**: Ensure you have Python 3.x installed on your system.
    ```bash
    python --version
    ```
-   **Jupyter Notebook**: For interactive execution of `.ipynb` files.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Anannya-Vyas/numpy.git
    cd numpy
    ```

2.  **Create and activate a virtual environment (recommended)**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install dependencies**
    Since there isn't a `requirements.txt` file, you'll need to install the commonly used libraries individually.
    ```bash
    pip install numpy pandas matplotlib seaborn scikit-learn jupyter rich ipykernel
    ```

4.  **Start Jupyter Notebook**
    ```bash
    jupyter notebook
    ```
    This will open a new tab in your web browser, showing the repository's contents.

5.  **Open a notebook**
    Click on any `.ipynb` file (e.g., `irisproject.ipynb`) to open it in Jupyter and start running the cells.
